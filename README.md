# Анонимный Discord-чек-ин в Telegram

Закрытый бот для небольшой компании друзей. Раз в день он присылает каждому личный опрос «Кто сегодня готов зайти в Discord?», принимает один из трёх статусов и показывает друзьям только общую сводку без имён. Если время не подходит, участник может написать своё — текст с ником увидят только администраторы.

## Как это выглядит

Участник получает в личном чате:

```text
Кто сегодня готов зайти в Discord?
Ответы принимаются до 23:00.

✅ Готовы: 3
🤔 Думают / позже: 2
❌ Не готовы: 1
⚪ Пока без ответа: 2

[✅ Готов] [🤔 Думаю / позже] [❌ Не готов]
[✍️ Смогу в другое время]
```

После «Другое время» бот попросит написать, например: «В 22:00 не смогу, буду в 22:30». Администратор сразу получит публичное имя, `@username` (если он есть) и Telegram ID. Повторное нажатие меняет ответ. После дедлайна кнопки исчезают, сообщение превращается в финальную сводку, а индивидуальные ответы и подписанные уточнения стираются.

## Что умеет

- работает только в личных чатах, в группах не принимает ответы;
- закрытая регистрация по ограниченным и истекающим ссылкам с выбором публичного имени;
- ручной или ежедневный автоматический опрос;
- три статуса, вариант «Другое время» и изменение ответа до дедлайна;
- мгновенное уведомление администраторов о каждом выборе и изменении ответа;
- `/details` показывает администраторам, кто что выбрал, кто не ответил и текстовые уточнения;
- отдельная админская рассылка текста, видео, фото, GIF, документов, аудио и голосовых без создания опроса;
- две Telegram Mini App-игры — «Змейка» и «Тап-спринт» — с общим рейтингом по публичным именам;
- сводка только в количествах, включая «без ответа»;
- автоматическое и ручное закрытие;
- публичные имена без Telegram-аккаунтов доступны друзьям через `/people`;
- соответствие «публичное имя → @username → Telegram ID» доступно только администраторам;
- удаление связи «участник → ответ» при закрытии опроса;
- удаление старых агрегатов через заданное число дней;
- запуск непривилегированным пользователем в read-only Docker-контейнере.

## Быстрый запуск

Понадобятся Docker и Docker Compose.

1. Откройте `@BotFather` в Telegram, выполните `/newbot` и сохраните токен.
2. Узнайте свой числовой Telegram ID, например через `@userinfobot`.
3. Скопируйте конфигурацию:

   ```bash
   cp .env.example .env
   ```

4. В `.env` обязательно заполните `BOT_TOKEN` и `ADMIN_IDS`. При нескольких администраторах перечислите ID через запятую.
5. Запустите:

   ```bash
   docker compose up -d --build
   docker compose logs -f bot
   ```

6. Напишите боту `/start` и задайте публичное имя. Администратор регистрируется автоматически. Создайте ссылку для друга командой `/invite` и передайте её лично. После открытия ссылки друг тоже должен выбрать уникальное имя.

Остановка: `docker compose down`. Данные находятся в именованном Docker-томе `bot-data` и не удаляются этой командой. Команда `docker compose down -v` удалит их безвозвратно.

## Обычный сценарий

1. Администратор отправляет каждому другу отдельную ссылку из `/invite`; участник выбирает видимое друзьям имя без раскрытия Telegram-аккаунта.
2. В заданное `DAILY_POLL_TIME` бот автоматически создаёт опрос. Если переменная пустая, администратор запускает его вручную: `/poll 23:00`.
3. Участники отвечают и при желании меняют статус. Если время не подходит, пишут свой вариант после кнопки «Другое время».
4. Бот закрывает опрос по дедлайну и обновляет исходные сообщения финальной сводкой.
5. Индивидуальные ответы удаляются; остаются только четыре числа.

## Команды

Для всех зарегистрированных:

- `/today` — снова показать сегодняшний опрос или итог;
- `/people` — публичные имена всех участников без Telegram username и ID;
- `/name Новое имя` — изменить своё публичное имя сразу;
- `/name` — бот попросит прислать новое имя следующим сообщением;
- `/games` — показать кнопку запуска игр;
- `/leaderboard` — рекорды «Змейки» и «Тап-спринта»;
- `/privacy` — коротко объяснить модель приватности;
- `/help` — справка.

Только для ID из `ADMIN_IDS`:

- `/invite` — одноразовая ссылка на 48 часов;
- `/invite 5 24` — ссылка на 5 регистраций, срок 24 часа;
- `/broadcast Текст сообщения` — разослать всем обычное сообщение без опроса;
- прикрепить медиа с подписью `/broadcast Посмотрите этот мем` — разослать файл с чистой подписью;
- ответить `/broadcast Посмотрите этот мем` на ранее отправленное боту видео или фото — разослать его всем;
- `/poll` — опрос с дедлайном через `DEFAULT_DEADLINE_HOURS`;
- `/poll 23:30` — дедлайн в 23:30 по `TIMEZONE`;
- `/poll 23:30 Собираемся сегодня в голосовом?` — свой текст;
- `/summary` — текущие агрегаты без имён;
- `/details` — закрытый админский список всех актуальных ответов и уточнений;
- `/close` — досрочно закрыть и стереть индивидуальные ответы;
- `/members` — закрытый админский список: публичное имя, @username и Telegram ID;
- `/revoke 123456789` — отключить доступ по Telegram ID.

Если указанное время уже прошло, `/poll HH:MM` поставит дедлайн на следующий день. Одновременно может быть открыт только один опрос. После `/close` можно сразу создать следующий — в том числе в тот же день. `/summary` всегда показывает последний опрос за сегодня.

### Рассылка без опроса

Администратор может отправить объявление или мем без кнопок:

```text
/broadcast Сегодня в 22:00 смотрим аниме
```

Для видео, фото, GIF или файла прикрепите его в Telegram и начните подпись с команды:

```text
/broadcast Зацените мем
```

Команда из подписи получателям не показывается — они увидят только `Зацените мем`. Другой вариант: сначала отправить файл боту, затем ответить на него командой `/broadcast Зацените мем`. Telegram-файл повторно не скачивается и не сохраняется в SQLite; бот копирует его каждому зарегистрированному участнику.

## Настройки `.env`

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | один или несколько числовых ID через запятую |
| `TIMEZONE` | часовой пояс IANA, например `Europe/Moscow` |
| `DAILY_POLL_TIME` | ежедневная рассылка `HH:MM`; пусто — только вручную |
| `DEFAULT_DEADLINE_HOURS` | длительность автоопроса и `/poll` без времени |
| `DATABASE_URL` | адрес SQLite; для Compose менять не нужно |
| `AGGREGATE_RETENTION_DAYS` | срок хранения обезличенных итогов |
| `LOG_LEVEL` | рекомендуется `INFO` |
| `MINI_APP_URL` | публичный HTTPS-адрес игровой страницы; пусто — игры отключены |

После изменения `.env` выполните `docker compose up -d --build`.

## Игровое Telegram-приложение

Исходный код находится в `game-site/`. Игры запускаются командой `/games`: бот показывает специальную кнопку под полем ввода. Такой тип кнопки позволяет странице вернуть результат тому же боту без отдельного игрового сервера. Бот связывает результат с Telegram ID отправителя, но в `/leaderboard` показывает друзьям только выбранное публичное имя.

Для работы нужен публичный HTTPS-адрес страницы. После публикации впишите его в `.env`:

```env
MINI_APP_URL=https://адрес-игры.example
```

Затем пересоберите контейнер. Сами игры выполняются на устройстве участника, поэтому рейтинг рассчитан на честную частную компанию и не является защищённым от технической накрутки.

### Production: Docker + GitHub + VPS

В production используются три контейнера: `bot`, `game` и `caddy`. Caddy принимает подключения на портах 80/443, автоматически получает TLS-сертификат и передаёт запросы игровому контейнеру. База бота остаётся в закрытом Docker-томе и через интернет не публикуется.

1. Создайте пустой GitHub-репозиторий и отправьте в него проект. Настоящий `.env` в GitHub не добавляйте.
2. Создайте DNS-запись типа `A`: игровой поддомен должен указывать на публичный IPv4 сервера.
3. На Ubuntu-сервере установите Docker Engine и Compose plugin, откройте TCP-порты 22, 80 и 443, а также UDP 443.
4. Клонируйте репозиторий на сервер и создайте `.env` из `.env.example`. Заполните `BOT_TOKEN`, `ADMIN_IDS` и `GAME_DOMAIN`. Переменную `MINI_APP_URL` в production Compose выставит автоматически.
5. Запустите весь комплект:

   ```bash
   docker compose -f compose.yaml -f compose.prod.yaml up -d --build
   docker compose -f compose.yaml -f compose.prod.yaml logs -f
   ```

Обновление после отправки нового кода в GitHub:

```bash
git pull --ff-only
docker compose -f compose.yaml -f compose.prod.yaml up -d --build
```

Файл `.github/workflows/ci.yml` автоматически проверяет Python-тесты, сборку Next.js и игровой Docker-образ при каждом push и pull request.

## Модель приватности

Бот обеспечивает **анонимность кнопочных ответов между друзьями**:

- друзья видят только агрегаты ответов и никогда не видят чужие Telegram username, ID или тексты уточнений;
- друзья могут открыть `/people`, но там находятся только выбранные публичные имена;
- Telegram username и ID из `/members` доступны только администраторам;
- администраторы сразу получают подписанное уведомление при любом выборе или его изменении;
- `/details` показывает администраторам публичное имя, Telegram username/ID и текущий ответ каждого участника;
- токены приглашений лежат в базе только в виде SHA-256-хешей;
- содержимое сообщений, Telegram ID и выборы не пишутся в лог;
- индивидуальный ответ нужен в открытом опросе только для изменения выбора;
- при закрытии индивидуальные ответы, ники и тексты уточнений физически удаляются с включённым SQLite `secure_delete`.

Честные ограничения:

- Telegram знает, кто общается с ботом;
- владелец сервера имеет технический доступ к базе и во время открытого опроса может сопоставить ID с ответом;
- все ID из `ADMIN_IDS` получают подписанные нажатия и текстовые уточнения и могут посмотреть текущие ответы через `/details`;
- человек с доступом к резервной копии открытого опроса тоже может это сделать;
- агрегаты маленькой группы иногда позволяют догадаться об ответе по времени изменения чисел.

Поэтому не публикуйте промежуточные скриншоты, ограничьте доступ к серверу и делайте резервные копии после закрытия опроса. Для большей скрытности от догадок можно договориться смотреть только финальный итог.

## Эксплуатация и защита

- Не отправляйте `.env`, токен бота и базу другим людям. `.env` исключён из Git.
- Передавайте инвайты лично. Для каждого друга лучше создавать отдельный `/invite`.
- Если ссылка утекла, новые регистрации по уже использованной одноразовой ссылке невозможны. Для многоразовой ссылки сейчас нет команды отзыва — используйте короткий срок жизни.
- Если друг заблокировал бота, рассылка покажет администратору только увеличение счётчика «не доставлено», без раскрытия ответа.
- Если токен бота утёк, отзовите его через BotFather и замените `BOT_TOKEN`.

## Резервная копия

Имя тома можно узнать командой `docker volume ls`. Безопаснее копировать базу, когда опрос закрыт и контейнер остановлен:

```bash
docker compose stop bot
docker run --rm -v discord-checkin-bot_bot-data:/data -v "${PWD}:/backup" alpine \
  tar czf /backup/discord-checkin-backup.tar.gz -C /data .
docker compose start bot
```

Фактический префикс тома зависит от имени папки; подставьте имя из `docker volume ls`. Резервная копия содержит Telegram ID участников — храните её как секрет.
